# Asteria 下一阶段：以统计模型结构为核心

日期：2026-09-08。性质：产品设计说明，不是实现任务。基于当前 `main` 提交 `80ad881bc88ad1caf017959e320e539028eb5a25` 的 README、TODO、AGENTS 和 2026-08-28 ROADMAP，以及用户本轮对 CAT-TRACE 模型说明的要求。

## 1. 产品判断

Asteria 最重要的任务不是把一项研究的所有文字放到画布上，而是让读者顺着模型理解：一个量是什么意思，属于哪个层级，如何定义或得到，需要哪些输入和假设，以及影响哪些下游结果。

因此下一阶段的主产品应当是**通用统计模型结构图**。模型内部的符号、数据、参数、潜变量、变换、目标量与估计方式是中心；论文背景、实验长表、日志、所有候选数据和项目待办不是同层节点。长篇推导仍由文档承担，图负责定位、依赖追踪与比较。

这个判断不是推翻 8 月 28 日 ROADMAP：其中已经把 Model Anatomy 设为第一优先级，并将 Model Lineage 与 Research/Evidence 分成独立视图。本轮进一步收敛为：**先把模型结构视图做成真正有用的产品，不并行实现三个完整知识图谱。** 方法谱系与研究证据保留为后续独立视图或链接，不能回流成第一张图里的信息堆积。

## 2. 一张图最少要回答的六个问题

用户点击某个符号后，应能在当前画布旁直接看到：

1. 它代表什么，是什么类型的对象？
2. 它在哪个层级，维数、索引和取值范围是什么？
3. 它怎样得到：测量、数据合并、固定设置、确定性公式、概率分布、优化还是估计方程？
4. 它使用哪些信息，依赖哪些条件或假设？
5. 它被哪些公式、目标或估计步骤使用？
6. 这个定义来自哪里，当前模型变体与其他版本有什么不同？

这里“怎样得到”比“有没有一个 prior”更一般。贝叶斯模型的先验只是其中一种关系，不是所有参数必须填写的字段。

## 3. 符号从文字表格升级成可引用对象

现有 Symbol block 是符号与含义列表，适合阅读，但还不能充分追踪符号在不同公式中的定义和使用。下一步应给模型对象建立稳定的内部身份；公式里的显示符号可以改名，内部引用不应因此失效。

最小对象信息是：显示名称/LaTeX、中文含义、对象角色、所属模型与层级、定义或来源、上游关系。维数、单位、索引范围、约束、推断方式和证据定位按需要展开，不要求用户一次填完一张复杂表。

对象角色至少能表达观测数据、未观察变量、未知参数、固定设置、确定性派生量、总体目标量与估计结果。角色可以扩展，但不要为每个术语增加一个新的彩色大卡片类型。

特别要区分：

- 参数 \(\theta\) 与估计量 \(\widehat\theta\)；
- 后验分布 \(p(\theta\mid D)\) 与估计量的抽样分布；
- 物种/特征容量与真实总体大小；
- 组标签这种数据与组效应这种待估参数；
- 总体目标、识别公式和具体估计器。

同一符号可以在不同模型中有不同含义，因此身份必须有模型作用域。不能把全项目里所有叫 \(\beta\) 的对象自动合并。相反，同一模型中的同一参数在多处出现，应能引用同一个定义，而不是复制多张容易冲突的说明卡。

## 4. 默认界面：分层主图、局部追踪、侧栏解释

默认打开模型结构视图，而不是包含论文所有内容的总画布。主图只展示少量层级和关键量；重复单位用索引范围或重复结构表示，不实际画出上千个物种、样本或参数节点。

以 CAT-TRACE 为例，主图可以先显示观测、潜在表示、目录/开放尾部参数、共享响应、残差结构、预测目标。点击开放尾部参数后，再展开组内截距、组强度及超参数，而不是一开始把每个半正态尺度全部铺开。

点击节点后，默认突出直接上游和下游；用户再选择继续追踪。侧栏同时显示自然语言解释、数学定义和来源。譬如点击 \(a_g\)，应知道它是从出现数据学习的组别环境响应，不是 taxonomy 文件直接给定的数值；点击 \(p_{\mathcal U,g}\)，应看到它是计算截断及稳定性检查规则，而不是物种总数估计。

层级是可配置的组织方式，不是写死的贝叶斯 hierarchy。提供贝叶斯、回归/优化和因果推断三个轻量模板即可。读图可以从观测往上追问，但箭头仍须按实际关系标注，不能因为视觉阅读顺序而把数据画成“生成先验”。

## 5. 边必须说明是什么关系

最重要的不是箭头颜色，而是它的语义。第一版只需一组清楚、可扩展的关系：

- 输入或数学依赖；
- 确定性变换；
- 条件分布/参数化；
- 使用数据估计；
- 在假设下识别；
- 近似或数值求解；
- 明确声明的因果影响。

“作为输入”“用于估计”和“产生随机变量”不能混作一种边。先验信息与数据证据也不能混成一条无说明的箭头。因果边必须由作者明确选择，普通相关或回归关系不自动升级为因果关系。

模型结构关系与计算信息流可以切换显示；不必第一版就做两个完整编辑器。假设可附在关系或公式上，使读者能看到某条识别式、独立性或简化在哪些前提下成立。

确定性同层循环可以提示作者检查；迭代算法、时间递推和动态反馈不能被一律判为错误。只有明确选择结构因果 DAG 的视图，才应用相应的无环要求，且仍不宣称图合法就证明因果可识别。

## 6. 必须用三个不同统计范式检验设计

### 6.1 贝叶斯层级模型：CAT-TRACE

点击观测 \(y^{\mathcal U}_{igh}\) 可以追踪到 \(z^{\mathcal U}_{igh}\)，再到截距、环境响应和归一化残差。点击组强度 \(\gamma_g\) 可以看到它由 \(\gamma_0\varpi_g\) 派生，不能再给它独立指定另一套先验。

对于 \(\gamma_0\)，侧栏要区分分布形式、数值超参数及来源。如果其均值用训练平均丰富度定标，必须显示“训练集经验定标”，而不是“外部生态事实”或“完全无信息”。对于 \(\lambda\)，要区分物种索引与因子索引。对于新发现目标，要区分固定超参数下的先验均值与已经条件于训练未检出的后验预测。

这个案例验证的不是 Asteria 能不能画很多公式，而是它能否暴露真实的层级/记号冲突。

### 6.2 频率学派回归或优化

例如

\[
y=X\beta+\varepsilon,\qquad
\widehat\beta=\arg\min_b\|y-Xb\|^2.
\]

\(X,y\) 是数据，\(\beta\) 是未知参数，\(\widehat\beta\) 是由优化规则得到的估计量。没有必要为 \(\beta\) 填先验，也不能因为这个字段为空而把模型标为不完整。

误差分布、秩条件、同方差等按分析需要附上；区间估计或抽样性质应链接到所用条件，不能把后验可信区间和频率置信区间使用同一种未标注的“不确定性”对象。相同图结构也应能表达惩罚项、交叉验证选定的调节参数以及估计方程。

### 6.3 因果推断

以平均处理效应为例，观测是协变量 \(X\)、处理 \(A\) 和结果 \(Y\)，目标为

\[
\tau=E\{Y(1)-Y(0)\}.
\]

结构图应区分潜在结果目标、作者声明的因果关系、可识别性假设、观测分布表达式和具体估计器。在一致性、条件交换性与正值性等条件成立时，才连接到

\[
\tau=E_X\{E(Y\mid A=1,X)-E(Y\mid A=0,X)\}.
\]

之后再连接到结果回归、加权或双重稳健估计等方法。Asteria 不自动证明这些条件，也不要求引入先验或潜在高斯变量。总体因果效应、识别后的统计泛函和有限样本估计值必须可以是不同对象。

这三个案例是产品验收样例，不是本轮给 Asteria 增加三个统计计算引擎。

## 7. 与现有架构衔接，而不是再次全量重写

8 月 ROADMAP 已提出对象内容与视图布局分离。延续这个方向：对象保存定义、符号、作用域、来源与语义关系；视图保存位置、折叠、局部可见性和阅读布局。图中同一对象的多次显示不复制数学定义。

第一步复用现有 React Flow、TipTap、Symbol、Inspector、搜索和版本解析功能。可以先允许作者把一段现有公式手动关联到符号对象，不要求先完成自动 LaTeX 解析器。未关联的旧内容仍可阅读编辑，不以新结构不完整为由丢弃。

现有顺序版本继承和 JSON/IndexedDB/共享保存必须保留。新对象信息作为可迁移的扩展加入，先验证旧地图往返保存。模型变体优先比较新增/改变的量、定义和假设；旧固定存档仍用于历史恢复，不与模型变体混为一谈。

不要一开始就新增庞大的本体、数据库服务、云账户或插件系统。能通过一个小模型的结构编辑、追踪和导出闭环验证价值，才继续扩大。

## 8. 导出：模型说明而不是 block dump

现有 Story Outline/Markdown 导出已在 README 中描述为实现功能，本轮不把它再次列为尚未完成的主任务。保留它用于线性汇报，但新的结构视图首先应导出**模型说明 Markdown**：

- 模型目的和作用域；
- 观测单位、数据来源及预处理；
- 按阅读顺序排列的层级、定义及公式；
- 唯一符号表；
- 参数怎样获得、依赖什么假设；
- 启用时的先验及超参数来源；
- 目标量、识别/预测关系和计算近似；
- 尚未解决的定义或信息缺口。

数学采用稳定的 LaTeX，正文脱离 Asteria 仍可阅读。机器导出则保留稳定对象 ID、类型和关系；人读正文不暴露机器字段。文档不取代画布，画布也不承担整篇论文的背景、实验和讨论。

## 9. 校核是提醒，不是假装自动审稿

第一版校核聚焦作者能够立即修复的结构问题：引用的符号没有定义；同一作用域出现冲突定义；索引范围缺失或复用歧义；标为派生量却又被重复赋独立先验；要求提供但未注明来源的数据；估计关系没有所用数据；显示为已识别结果但没有链接前提。

只有明确声明维数、分布约束时，才进行相应的机械检查；不能通过简单字符串匹配宣称证明公式正确、先验适当或因果识别成立。证据缺口可以保留并提示，不为“图完整”自动编造先验、数据或假设。

## 10. 收敛后的开发顺序

第一阶段：建立作用域内符号对象及手动引用，升级侧栏，让含义、层级、来源和定义可追踪；保留旧块内容与版本。

第二阶段：增加最小语义关系、可配置层级、索引重复结构与上游/下游局部显示；用三个范式小样例检验没有贝叶斯锁定。

第三阶段：导出模型说明与符号表，验证导入/导出往返、旧地图兼容和基础结构提醒。

模型谱系、研究证据图、自动抽论文、AI 推断模型、复杂语义差异和统计计算插件均后置。除非用户重新授权，不把本说明自行扩写成大规模应用重构。
