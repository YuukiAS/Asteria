## Authority Boundary

The concept images define the visual and interaction language for layout, density, focus states, view structure, and design tone. They are not mathematical, citation, simulation-status, real-data-status, or authorship sources of truth.

If any formula, author, citation, state label, result status, or numerical claim inside an image conflicts with the current canonical references, the image content must be ignored and the canonical text references must be used instead.
